Checkly Recorder
설치 안내

Chrome에 Checkly Recorder를 직접 추가하는 방법을 처음부터 차근차근 안내합니다.

시작하기 전에

컴퓨터에 Google Chrome 120 이상과 전달받은 확장프로그램 ZIP 파일이 필요합니다.

확장프로그램 ZIP 받기 ↓

이 HTML과 ZIP을 같은 폴더에 두고 공유하면 버튼을 사용할 수 있습니다. ZIP을 따로 받았다면 다시 받을 필요는 없습니다.

01 · Chrome에 설치하기

심사 전에는 압축을 푼 폴더를 Chrome에 직접 등록합니다. ZIP 파일 자체를 선택하는 방식은 아닙니다.

  1. ZIP 파일을 다운로드하고 압축을 풀어 주세요.

    Windows: ZIP 파일을 마우스 오른쪽 버튼으로 클릭 → 압축 풀기 또는 모두 압축 풀기.
    Mac: ZIP 파일을 두 번 클릭합니다.

    압축을 풀어 만든 폴더를 열어 manifest.json 파일이 들어 있는지 확인하세요. 확장자가 숨겨진 경우 manifest로 보일 수 있습니다.

    화면 예시 · 사용하는 운영체제와 Chrome 버전에 따라 모습이 다를 수 있습니다.

    설치 후에도 압축을 푼 폴더를 삭제하거나 다른 곳으로 옮기지 마세요. 다운로드 폴더 정리 전에 보관할 위치를 정하는 것이 좋습니다.
  2. Chrome에서 확장 프로그램 관리 화면을 엽니다.

    Chrome 주소창을 클릭하고 아래 주소를 직접 입력한 뒤 Enter를 누릅니다.

    chrome://extensions

    또는 Chrome 오른쪽 위 ⋮ → 확장 프로그램 → 확장 프로그램 관리로 이동합니다.

    화면 예시 · 사용하는 운영체제와 Chrome 버전에 따라 모습이 다를 수 있습니다.

  3. 오른쪽 위의 ‘개발자 모드’를 켭니다.

    스위치를 켜면 화면 위쪽에 설치 버튼이 나타납니다.

    화면 예시 · 사용하는 운영체제와 Chrome 버전에 따라 모습이 다를 수 있습니다.

  4. ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다.

    파일 선택 창에서 1단계의 manifest.json이 바로 들어 있는 폴더를 선택한 뒤 폴더 선택 또는 열기를 누릅니다. 파일이나 ZIP이 아니라 폴더를 선택해야 합니다.

    화면 예시 · 사용하는 운영체제와 Chrome 버전에 따라 모습이 다를 수 있습니다.

    폴더 안에 또 다른 폴더가 보이면 그 안을 열어 manifest.json이 있는 폴더를 선택하세요. 전달받은 ZIP이 이 안내서의 0.1.2 패키지라면 압축을 푼 폴더가 대상입니다.
  5. Checkly Recorder가 목록에 나타나는지 확인합니다.

    Chrome 오른쪽 위 퍼즐 모양 확장 프로그램 아이콘을 누르고, Checkly Recorder 옆의 핀을 누르면 도구 모음에 고정할 수 있습니다.

    화면 예시 · 사용하는 운영체제와 Chrome 버전에 따라 모습이 다를 수 있습니다.

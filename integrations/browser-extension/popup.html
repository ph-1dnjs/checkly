도움말

이렇게 사용해요

  1. 기록 시작테스트할 탭에서 기록 시작을 누르세요.
  2. 오류 재현평소처럼 사용하세요. 오류가 나면 전·후 구간이 자동으로 저장돼요.
  3. 확인 후 서버로 전송기록을 열어 다시 보고, 참고사항을 남긴 뒤 서버로 전송하세요.
  4. Checkly 앱에서 확인Checkly 앱 › 브라우저 기록 › 서버 탭에서 전송한 기록을 팀과 함께 볼 수 있어요.

자주 묻는 질문

입력한 비밀번호도 기록되나요?

입력값과 화면 텍스트는 마스킹 없이 저장됩니다. 비밀번호와 개인정보가 포함될 수 있습니다.

기록은 언제 팀에 공유되나요?

자동으로 올라가지 않아요. 직접 선택해 서버로 전송한 기록만 Checkly 앱 › 브라우저 기록 › 서버 탭에 나타나요.

오류가 없으면 어떻게 되나요?

오류가 감지되지 않으면 기록이 저장되지 않습니다.

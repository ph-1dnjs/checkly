# Checkly Chrome Extension

Manifest V3 확장 프로그램. 체클리 팀 계정으로 로그인하고 선택한 탭의 오류 전후 5초 화면을 로컬에 보관하고 사용자가 선택한 기록만 기존 서버에 전송합니다. 같은 프로젝트의 체클리 앱에서 **브라우저 기록 → 서버**를 선택해 재생합니다. 기존 공통 테이블과 서버 스키마는 변경하지 않습니다.

## 설치

1. `npm ci` 후 `npm run build` (Node 22 이상).
2. Chrome `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `dist` 선택.
3. 테스트 사이트를 연 뒤 확장 아이콘을 눌러 사이드 패널을 열고 기존 프로젝트 코드·닉네임·비밀번호로 로그인.
4. 수집 안내 동의 후 **재생 아이콘(모니터링 시작)**. 해당 사이트 권한을 허용합니다.
5. JS 오류 / 미처리 Promise / console.error / fetch·XHR 실패가 발생하면 전후 기록을 수집합니다. 확장프로그램의 화면 기록 목록에서 **미리보기**를 눌러 바텀시트에서 마스킹된 화면 재생을 확인하고 참고사항을 작성할 수 있습니다. 오류 메시지 원문은 수집하지 않습니다. 원하는 항목을 체크하고 **선택한 기록 전송**을 누릅니다. 실패한 기록은 로컬에 남습니다.
6. 체클리 앱에서 동일한 프로젝트로 로그인 → 브라우저 기록 → 서버 → 기록 선택.

스토어 업로드: `dist`의 **내용**을 ZIP으로 묶어 제출합니다. 프로젝트 소스·node_modules·테스트 파일은 포함하지 않습니다. 개발자 등록만으로 심사가 완료되지는 않습니다.

패널은 탭을 옮겨도 열린 상태를 유지하며 현재 선택한 탭을 표시합니다. Chrome 설정에서 패널 위치를 바꾸고 경계를 드래그해 크기를 조절할 수 있습니다. 기록 목록은 로컬 저장 완료 알림을 받아 자동으로 갱신합니다. **새로고침**은 수동 확인용으로도 사용할 수 있습니다.

## 화면 캡처

사이드 패널 상단의 **카메라 아이콘(현재 화면 캡처)**를 누르면 현재 보이는 탭을 촬영하고 별도 편집 탭을 엽니다. 영역 선택, 펜, 네모, 체크, 텍스트, 지우개와 실행 취소를 사용한 뒤 클립보드로 복사할 수 있습니다. 캡처는 오류 기록의 마스킹이 적용되지 않으며 서버로 자동 전송되지 않습니다. 패널 버튼은 필요할 때 사이트 접근 권한을 요청합니다. Chrome에서 기본 단축키 macOS `Command + Shift + S`, Windows/Linux `Alt + Shift + S`로도 현재 탭을 캡처할 수 있습니다. 단축키 충돌 시 `chrome://extensions/shortcuts`에서 확인하거나 변경하세요.

## 동작과 범위

- 선택한 탭의 같은 origin에서 새로고침·페이지 이동·SPA 이동을 지원합니다. 다른 origin으로 이동하면 중지합니다. 새 탭·팝업은 별도로 시작합니다.
- rrweb DOM 재생이며 화면 영상은 아닙니다. iframe·canvas·video·audio는 제외합니다.
- 입력값과 모든 화면 텍스트를 마스킹합니다. 페이지 제목은 수집하지 않습니다. URL 쿼리·해시·사용자 정보, 민감 DOM 속성을 제거합니다. URL 경로와 일부 DOM 속성에는 업무 데이터가 포함될 수 있으므로 승인된 테스트 사이트에서 사용하세요.
- API 본문·헤더·쿠키·오류 메시지 원문은 수집하지 않습니다. API 상태·종류·URL과 화면 동작을 기록합니다. Worker 안의 API 호출, 설치 이전 오류, 브라우저 내부 페이지는 수집 대상이 아닙니다.
- 오류 전 5초를 재구성하기 위한 이전 전체 스냅샷도 포함합니다. 초기 시작 직후나 탭 종료 시 5초 미만일 수 있습니다. 동일한 후속 5초 안의 오류는 한 기록으로 묶습니다.
- 기록은 IndexedDB에 보관하고 사용자가 선택해 전송에 성공하면 로컬에서 삭제합니다. 선택한 로컬 기록을 직접 삭제할 수도 있습니다. 최대 대기 20건/약 40MB, 활성 버퍼 약 6MB, 개별 클립 약 8MB입니다. 한도 도달 시 오류를 표시합니다.
- 서비스 워커 재시작에 대비해 활성 기록과 대기 기록을 보관합니다. 로그아웃은 수집을 중지하고 토큰을 지웁니다. 로컬 기록은 같은 사용자·프로젝트로 로그인해야 확인하고 전송할 수 있습니다. 브라우저 종료 시 로그인 세션은 사라집니다.
- 확장 삭제 또는 브라우저 확장 저장소 삭제로 로컬 대기 기록을 삭제할 수 있습니다. 서버 기록은 체클리 앱에서 삭제합니다.

## 서버 계약

`src/config.js`의 배포용 서버 주소와 **공개 anon 키**를 사용합니다. service_role 키는 사용하지 않습니다. 인증 토큰은 신뢰된 확장 컨텍스트에서만 접근 가능한 `chrome.storage.session`에 둡니다.

업로드 파일: `browser-error-replays/{projectId}/{userId}/{recordingId}.json.gz`

파일 구조: `{ session, documents, logs }`. `session.source = "browser"`, UUID 기반 식별자 및 기존 `LiveSession`/`SessionRecording` 계약을 유지합니다. `form_browser_recordings`에 metadata와 object_path를 upsert합니다. 프로젝트 접근은 기존 RLS가 검증합니다. 로그는 재생 파일에 포함되며 별도 `form_browser_logs` 테이블에는 쓰지 않습니다.

## 검증

- `npm test`: 오류 구간·문서 이동·중복 오류·마스킹 URL·gzip·업로드 계약·계정 격리·실패 보존.
- `npx playwright-core install chromium` 후 `npm run test:browser`: 로컬 테스트 페이지에서 실제 Chromium의 수집·HTTP 500·마스킹·rrweb 재생.
- `npm run test:extension`: 격리된 Chromium 프로필에 실제 Manifest V3 확장을 로드하고 로그인 화면·서비스 워커 시작을 확인합니다.
- 실제 팀 서버 업로드와 Electron 앱 UI의 종단간 검증은 사용자 계정으로 위 설치 절차를 수행해야 합니다. 테스트에서 운영 계정·비밀번호를 만들거나 사용하지 않습니다.

## Unlisted 출시 준비

실사용자 테스트 후 스토어 설명·스크린샷·지원 연락처·공개 개인정보처리방침 URL을 등록하고 수집 항목과 권한 사용 목적을 신고하세요. `PRIVACY.md`는 검토·게시할 초안이며 공개 URL이 아닙니다. 모든 실행 코드는 번들에 포함하며 원격 코드를 실행하지 않습니다.

## 사이드 패널 UI

- 상단에 닉네임과 상태 표시등, 시작·중지, 카메라, 도움말, 더보기 메뉴를 표시합니다. 로그아웃은 더보기 메뉴에서 실행합니다.
- 화면 기록을 한 화면에서 확인합니다. 수집 중에는 닉네임 옆 초록색 표시등과 상단 중지 아이콘이 나타납니다. 물음표 도움말은 호버·키보드 포커스로 확인합니다.
- 화면 기록 목록에서 미리보기, 새로고침, 선택 전송·삭제 아이콘을 사용합니다.
- 수집 동의는 브라우저 프로필의 확장 저장소에 한 번 저장되어 패널을 다시 열거나 로그인해도 유지됩니다. 사이트 접근 권한은 Chrome에서 별도로 요청합니다.
- `npm run test:panel`: 격리된 Chrome의 실제 UI에서 mock 계정·기록으로 상단 컨트롤, 동의 유지, 시작/중지, 도움말, 선택 전송 및 계정 메뉴를 검증합니다. 운영 서버는 호출하지 않습니다.

### 기록 미리보기와 참고사항

미리보기는 목록 스크롤과 분리된 모달 바텀시트입니다. 화면 중앙 버튼으로 재생·일시정지하며, 여러 페이지로 이동한 기록도 이어서 재생합니다. 닫기·Escape·배경 클릭으로 닫을 수 있습니다. 하단 **서버로 전송** 버튼은 작성 중인 참고사항 저장을 완료한 뒤 현재 미리보기 기록 한 건만 전송합니다. 전송 중에는 중복 클릭과 편집을 막고, 실패하면 시트를 유지해 재시도할 수 있습니다.

참고사항은 최대 5,000자이며 로컬 기록의 `session.notes`에 자동 저장됩니다. 시트를 닫을 때 미저장 내용을 먼저 저장하며, 실패하면 입력을 유지하고 재시도를 안내합니다. 체크한 기록을 서버로 전송할 때 gzip 재생 파일과 기존 `form_browser_recordings.metadata`에 함께 포함됩니다. DB 스키마 변경은 없으며 체클리 앱의 서버 기록 상세에서도 참고사항을 표시합니다.

### 자동 갱신과 진행 표시

오류 화면을 수집하는 동안 약 5초의 수집 진행률을 표시하고, 수집이 끝나면 로컬 저장 상태를 표시합니다. IndexedDB 트랜잭션 완료 후 변경 알림으로 목록을 자동 갱신하며, 기존 선택과 미리보기의 참고사항은 유지됩니다. 기록 본문의 이벤트나 참고사항만 바뀐 경우에는 불필요한 목록 갱신을 보내지 않습니다.

서버 전송은 여전히 사용자가 선택한 기록에만 실행됩니다. 목록과 미리보기 모두 전송 준비 → 파일 업로드 → 서버 기록 저장 단계와 완료 건수를 표시합니다. 업로드 API가 바이트 진행률을 제공하지 않아 전송 중에는 움직이는 진행 막대를 사용하며 임의의 백분율은 표시하지 않습니다. 실패한 기록은 로컬에 남습니다.

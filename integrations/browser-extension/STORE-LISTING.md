## 상세 설명

웹사이트를 테스트하다 발생한 오류와 당시 화면 흐름을 체클리 팀에 공유하세요.

Checkly Recorder는 사용자가 선택한 탭에서 오류 발생 전후 약 5초의 화면 구조와 동작을 기록합니다. 선택한 기록은 로그인한 체클리 프로젝트의 서버로 전송되며, 같은 프로젝트의 체클리 앱에서 재생할 수 있습니다.

주요 기능
• JavaScript 오류, 미처리 Promise, console.error 및 fetch/XHR 실패 감지
• 오류 전후 화면 흐름 기록과 같은 사이트 내 페이지 이동 추적
• 로컬 기록 선택 전송 및 실패한 업로드 보관
• 입력값과 화면 텍스트 마스킹
• 사이트별 접근 권한 요청 및 수집 중지

사용 방법
1. 기존 체클리 프로젝트 계정으로 로그인합니다.
2. 테스트할 웹사이트 탭에서 수집 안내에 동의하고 모니터링을 시작합니다.
3. 오류 기록 전송 후 체클리 앱의 브라우저 기록 → 서버에서 재생합니다.

체클리 계정과 데스크톱 앱이 필요합니다. URL 경로 및 일부 화면 속성에는 사이트의 업무 데이터가 포함될 수 있으므로 수집 권한이 있는 테스트 사이트에서 사용하세요. iframe, canvas 및 미디어 재생은 기록 대상에서 제외됩니다.

## 단일 목적

사용자가 선택한 웹 테스트 탭의 오류 전후 화면 흐름을 수집하여 체클리 프로젝트에서 오류를 진단하고 재생하도록 지원합니다.

## 권한 사용 사유

storage: 로그인 세션, 모니터링 상태 및 실패한 전송 기록을 관리합니다.
scripting: 사용자가 허용한 사이트에 화면 기록기와 오류 감지기를 실행합니다.
activeTab: 사용자가 선택한 탭을 기록하고 요청 시 화면을 캡처합니다.
clipboardWrite: 편집한 캡처 이미지를 사용자가 요청할 때 클립보드에 복사합니다.
sidePanel: 브라우저 옆에 확장 프로그램 화면을 표시합니다.
tabs: 선택한 탭과 URL을 확인하고 캡처 편집 탭을 엽니다.
alarms: 서비스 워커가 유휴 상태가 된 후에도 오류 기록 수집을 마무리합니다.
서버 호스트 권한: 체클리 Supabase 서버에 인증하고 오류 기록을 전송합니다.
선택적 전체 사이트 권한: 패널에서 임시 권한이 없는 현재 탭을 캡처할 때 사용자에게 요청합니다.
선택적 HTTP/HTTPS 호스트 권한: 사용자가 선택하고 허용한 테스트 사이트에서만 오류와 화면 흐름을 수집합니다.
원격 코드: 사용하지 않습니다. 실행 코드는 확장 패키지에 포함됩니다.

- 공개 개인정보처리방침 URL(현재 PRIVACY.md는 초안)

- 심사자가 로그인 기능을 확인할 수 있는 테스트 계정 또는 재현 가능한 검토 안내
- 실제 서버 전송 및 체클리 앱 재생 최종 확인

민감한 심사용 계정 정보는 이 파일이나 저장소에 넣지 않고 대시보드의 검토용 비공개 항목에 입력합니다.

## 2026-11-12 시안 비교

`npm run build` 후 `node tests/visual-review.mjs`로 사용자 제공 HTML과 빌드된 확장 UI를 같은 폭·높이로 캡처한다. 프로젝트 루트의 `*Recorder 1.html` 원본이 필요하다. 결과는 `outputs/recorder-design-review/comparison.html`과 폭별 overview 이미지에 남긴다.

- 380 / 560 / 760px에서 로그인·동의·대기·기록 중·목록·미리보기·도움말·더보기 및 캡처 편집기: 총 27쌍.
- Chrome 고정 헤더에 해당하는 시안 상단 48px는 비교에서 제외한다. 확장 UI에 커스텀 헤더를 추가하지 않는다.
- 빌드 UI를 로드하되 Chrome API와 계정·기록 데이터는 테스트 fixture를 사용한다. 미리보기는 rrweb 형식의 실제 DOM 스냅샷을 재생한다. 캡처는 시안 데모 페이지를 이미지로 가져와 실제 편집 컴포넌트에 전달한다. 구현 UI를 시안 이미지로 대체하지 않는다.
- JavaScript 오류·가로 넘침 검사 및 미리보기 재생/일시정지·전체 선택·도움말 닫기 확인.
- 글꼴·원본 로고·시작/중지 아이콘·캡처 SVG 도구·툴바 box sizing·목록 간격·대화상자 높이·600px 이상 중앙 대화상자 규칙을 보정했다.

의도적인 차이: 개인정보 수집 안내 및 오류 전후 구간은 실제 동작을 설명한다. 시안의 가상 팀 이름/버전/캐시 용량/재생 썸네일/캡처 주석을 실제 데이터인 것처럼 표시하지 않는다. 기억하기는 저장 동의가 없는 최초 화면에서 꺼져 있다. 추가된 자동 저장 상태와 동작 가능한 재생 바를 유지한다. 이 검증은 운영 계정 인증·업로드 종단간 테스트나 모든 픽셀이 같다는 판정을 의미하지 않는다.

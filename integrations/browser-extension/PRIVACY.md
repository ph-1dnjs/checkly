## 처리 목적과 수집 항목

Checkly Recorder는 사용자가 선택한 테스트 탭의 오류를 진단하고 같은 체클리 프로젝트 팀원과 오류 전후 화면 흐름을 공유하기 위한 확장 프로그램입니다.

로그인 과정에서 프로젝트 코드·닉네임·비밀번호를 체클리 인증 서버로 전송합니다. 비밀번호는 확장 프로그램에 저장하지 않습니다. 인증 세션 정보는 브라우저 세션 동안 확장 프로그램의 신뢰된 컨텍스트에 저장됩니다.

사용자가 수집 안내에 동의하고 모니터링을 시작하면 선택한 탭의 화면 구조, 클릭·스크롤·페이지 이동, 오류 종류, API 요청의 URL·메서드·상태 및 발생 시각을 처리합니다. 오류 발생 전후 약 5초의 재생 기록을 로컬에 저장하고 사용자가 선택한 기록을 서버에 전송합니다. 화면을 재구성하기 위해 해당 구간 이전의 전체 스냅샷이 포함될 수 있습니다.

입력값과 화면 텍스트는 마스킹합니다. URL의 쿼리·해시·사용자 정보를 제거하며 API 본문·쿠키·인증 헤더·오류 메시지 원문을 수집하지 않습니다. 다만 URL 경로 및 일부 DOM 속성에 사이트의 업무 데이터나 개인정보가 포함될 수 있습니다. 사용자는 수집 권한이 있는 테스트 사이트에서만 사용해야 합니다.

## 저장과 접근

기록은 HTTPS를 통해 체클리 서버로 전송하고 Supabase의 비공개 파일 저장소 및 데이터베이스에 저장합니다. 같은 프로젝트의 권한 있는 팀원이 체클리 앱에서 기록을 조회·재생할 수 있습니다. 데이터를 광고에 사용하거나 판매하지 않습니다.

## 보관과 삭제

서버에 전송된 브라우저 오류 기록과 로그는 서버에 저장된 시각부터 30일이 지난 뒤 매일 자동 삭제합니다. 정기 작업 지연이나 실패 시 삭제가 늦어질 수 있습니다. 체클리 앱의 브라우저 기록에서 서버 기록을 직접 삭제할 수도 있으며, 삭제 시 해당 기록 파일과 DB 목록을 삭제합니다. 자동 삭제는 이 PC에 저장된 로컬 기록을 삭제하지 않습니다. 개인정보 관련 요청은 위 지원 이메일로 문의할 수 있습니다.

오류 기록은 브라우저에 보관하며 사용자가 선택한 기록만 서버에 전송하고 전송 성공 시 로컬 사본을 삭제합니다. 모니터링 상태와 활성 버퍼도 브라우저에 저장될 수 있습니다. 로그아웃은 수집을 중지하고 인증 세션을 지우며, 보관된 기록은 같은 계정에서 확인하고 전송하거나 삭제할 수 있습니다. 확장 프로그램 삭제 또는 브라우저의 확장 저장소 삭제로 로컬 데이터를 삭제할 수 있습니다.

## 사용자 선택

사용자는 사이트별 접근 권한을 허용하거나 거부하고, 모니터링을 시작·중지하거나 로그아웃할 수 있습니다. 다른 사이트로 이동하면 해당 탭의 모니터링은 중지됩니다. 권한을 철회하거나 확장 프로그램을 제거할 수 있습니다.

## 방침 변경

처리 항목이나 보관 방식이 변경되면 이 문서의 시행일과 내용을 갱신합니다.

화면 캡처는 사용자가 직접 요청할 때 현재 표시된 탭을 촬영합니다. 화면 캡처에는 오류 기록의 마스킹이 적용되지 않으며, 편집 화면에서 사용한 뒤 사용자의 요청으로 클립보드에 복사합니다. 캡처를 서버로 자동 전송하지 않습니다.

사용자가 작성한 참고사항은 해당 기록과 함께 로컬에 저장되며, 기록을 선택해 전송할 때 서버에도 함께 저장되어 같은 프로젝트의 권한 있는 팀원이 확인할 수 있습니다.

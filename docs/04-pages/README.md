## 화면 전환

URL 라우터는 없습니다. `BottomNavigation`과 각 페이지 callback이 `App.route`를 바꿉니다. 실행 화면은 하단 메뉴에 직접 노출되지 않으며 실행 시작, 대시보드의 전체 실행, 실행 알림 바로가기로 진입합니다.

```mermaid
flowchart LR
  D[대시보드] --> P[시나리오 선택]
  D --> R[실행]
  E[편집기] --> R
  E --> P
  P --> E
  P --> R
  R --> P
  R --> D
  S[설정]
```

실행은 다른 화면을 보고 있어도 계속되며 우측 알림에서 진행·완료 상태와 실행 화면 바로가기를 제공합니다.

# [사용자 흐름] 시나리오 편집

```mermaid
flowchart TD
  A[편집기] --> B[Markdown 수정 또는 파일 불러오기]
  B --> C[parseMarkdown 미리보기]
  C --> D{마커 편집?}
  D -->|예| E[대상 페이지 검사·마커 수정]
  D -->|아니오| F[저장 또는 실행]
  E --> F
```

| 사용자 액션 | 화면·시스템 동작 |
| --- | --- |
| 저장 | 현재 Markdown을 앱 저장소 또는 선택된 파일에 기록 |
| 파일 불러오기 | Markdown을 읽고 활성 파일 경로 설정 |
| 화면에서 추출 | Playwright 검사 후 연결 상태 표시 |
| 마커 추가/수정 | 단계와 좌표를 변경하고 위치 저장 |

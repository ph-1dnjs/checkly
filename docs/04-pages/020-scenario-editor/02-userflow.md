# 사용자 흐름·상태 전이

1. 로그인 후 프로젝트의 DB 문서 목록을 조회한다.
2. **새 시나리오**로 초안을 만들거나 목록의 문서를 연다.
3. Markdown과 마커를 편집한다. 템플릿 복제는 현재 문서에 블록을 추가한다.
4. **저장** 또는 ⌘/Ctrl+S로 본문·좌표를 함께 저장한다. 성공한 응답의 버전을 다음 수정에 사용한다.
5. 실행 대상 화면에서 저장된 블록을 선택하거나 편집기에서 현재 초안을 실행한다. 실행 자체는 DB에 저장하지 않는다.
6. **삭제** 확인 후 현재 문서를 DB에서 삭제한다. 실패하면 문서와 초안을 유지한다.

새 작성·다른 문서 열기·편집기 새로고침은 미저장 내용이 있으면 버리기 확인을 거친다. 취소하면 초안을 유지한다. 앱 종료·전체 새로고침은 저장을 대신하지 않으므로 먼저 명시적으로 저장한다.

화면 추출에서 텍스트로 돌아올 때 저장을 선택하면 성공한 경우에만 복귀한다. 실패·충돌이면 마커 편집과 확인창을 유지한다. 저장하지 않고 복귀는 현재 메모리의 마커를 DB에 저장하지 않는다.

엔드포인트·환경은 공통 설정을 읽고 개인 선택만 로컬에 저장한다. 설정을 바꾼 후 시나리오 화면의 새로고침으로 다시 읽는다.

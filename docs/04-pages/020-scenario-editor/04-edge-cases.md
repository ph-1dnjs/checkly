# [엣지 케이스] 시나리오 편집

| 상황 | 현재 동작 | 영향 / 다음 행동 |
| --- | --- | --- |
| 기본 저장 load 실패 | 토스트, seed로 계속 | 저장소 권한 확인 |
| 외부 dialog 취소 | null, 상태 유지 | 재선택 가능 |
| 외부 파일 쓰기 실패 | 토스트 | 원문은 화면에 남음 |
| 잘못된 Markdown | 인식된 블록·단계만 미리보기 | 문법 수정 |
| URL 없음 | seed URL 사용 | 의도하지 않은 검사·실행 가능 |
| inspect 실패 | 토스트 | marker 수동 편집 가능 |
| 후행 단계에서만 나타나는 target | inspect는 기본 URL만 보므로 unlinked 가능 | 실제 실행과 차이 인지 |
| 미연결 marker | 목록에 unlinked, pin 미표시 | 편집·재연결 |
| target 빈 marker | 완료 버튼 비활성 | label 입력 |
| marker 직렬화 | `tag:`를 출력하지 않음 | tag 유실 가능 |
| 저장 안 하고 복귀 | marker 변경을 원문에 반영하지 않음 | marker 좌표는 별도 저장될 수 있음 |
| upload 절대 경로 | 다른 컴퓨터에서 무효할 수 있음 | 실행 머신에서 재선택 |

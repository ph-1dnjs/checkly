# 예외 처리·검증

| 상황 | 처리 |
| --- | --- |
| 비로그인·Supabase 비활성 | 로그인 안내, DB·기존 파일 접근 없음 |
| 목록 조회 실패 | 한국어 오류 토스트, 기존 목록 유지, 새로고침 가능 |
| 빈 원문 | 편집기 유지, DB 저장 차단 |
| 저장·삭제 충돌 | 다른 팀원 수정 안내, 초안 유지, 새로고침 후 다시 편집 |
| 저장 중 중복 클릭 | 한 번의 저장만 실행 |
| 저장 중 추가 편집 | 저장한 스냅샷 이후 변경은 미저장 상태로 남음 |
| 삭제 취소 | 문서와 초안 유지 |
| 엔드포인트 × 환경 주소 없음 | 설정 안내, 실행 차단 |
| 로그아웃·프로젝트 전환 | Workspace 제거 또는 앱 재시작으로 이전 상태 폐기 |

마커 매칭은 제목+URL 및 단계 속성을 사용한다. 동일 속성의 반복 단계나 제목·URL 변경에서 좌표 연결에는 기존 모델의 제한이 있다. Markdown 직렬화의 세부 제한은 [기능 문서](01-overview.md)를 참고한다.

`tests/web-scenarios.spec.ts`는 mock DB IPC로 CRUD, 충돌, 초안 보호, 비로그인, 조회 오류 및 환경 복원을 검사한다. 실제 DB RLS·원자성·동시 수정은 `tests/auth/web-scenario-store.test.ts`에서 로컬 Supabase가 있을 때 검증한다. 브라우저 mock 테스트는 실제 Electron WebView·Playwright 실행 검증을 대체하지 않는다.

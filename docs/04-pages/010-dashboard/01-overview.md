# [개요] 대시보드

조회 기준: 2026-11-17 작업 트리. DB 마이그레이션의 실제 적용 여부는 별도 확인이 필요합니다.

로그인한 팀 프로젝트의 최근 7일·30일 또는 직접 선택한 기간(최대 366일)을 조회합니다. 전체·웹·API 탭과 상태·환경·이름·날짜 필터, 목록 페이지 이동을 제공합니다. 날짜는 기기 시간대의 시작일 00:00부터 종료일 다음 날 00:00 직전까지입니다.

웹은 실행 묶음, API는 시나리오 실행을 각각 한 건으로 셉니다. 성공률은 성공 / (성공 + 실패)이며 취소와 설정 필요를 제외합니다. 웹 소요 시간 중앙값은 완료된 실행의 시작·종료 시각 차이로 계산합니다. 조회된 기간에 실패 또는 설정 필요 상태인 최근 실행 최대 5개를 확인 필요에 표시합니다.

웹 실행 행은 저장된 상세를 열고 재실행할 수 있습니다. API 실행 행은 상태·환경·시각을 요약해 보여 주며 API 테스트 화면으로 이동할 수 있습니다. 과거 요청·응답 상세는 팀 DB에 보관하지 않습니다.

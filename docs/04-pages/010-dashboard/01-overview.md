# [개요] 대시보드

> **범위**: 하단의 실행 기록 진입부터 기록 상세 열기·재실행·실행 화면 이동까지입니다.

## 표시 정보

- 전체 실행 묶음 중 성공 비율과 실패 묶음 수
- 최근 기록별 예상 시간의 정렬된 중앙 요소
- 상태 tape
- 최근 5개 실행의 묶음명, 시나리오명, pass rate, 예상 시간, 시작 시각
- 기록별 상세 서랍과 다시 실행

통과율은 시나리오 단계가 아니라 실행 묶음 단위 `runSummary`로 계산합니다. 시간은 실측값이 아니라 `estimateDurationSeconds`의 합입니다.

기록은 취소되지 않고 큐 처리가 끝난 실행만 생성됩니다. 실패한 시나리오가 하나라도 있으면 묶음 상태는 failed입니다.

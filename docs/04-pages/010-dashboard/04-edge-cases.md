# [엣지 케이스] 대시보드

| 상황 | 현재 동작 |
| --- | --- |
| 로그인하지 않음 | DB를 조회하지 않고 로그인 안내를 표시 |
| 기록 없음 | 성공률과 중앙값은 `—`, 실행 화면 이동 제공 |
| 취소 또는 설정 필요 | 성공률 분모에서 제외 |
| 삭제된 환경 | 기존 환경 ID는 유지하며 삭제된 환경으로 표시 |
| 웹 묶음의 환경이 없거나 서로 다름 | 환경 정보 없음으로 표시 |
| API 기록 저장 실패 | API 실행 결과는 유지하고 저장 실패를 안내 |
| API 과거 상세 | 집계용 메타데이터만 팀 DB에 있어 과거 요청·응답은 복원하지 않음 |
| API 실행 전 스위트 검증 실패 | 설정 필요 상태로 저장하며, 앞 실행 실패 정책으로 건너뛴 항목은 제외 |
| 조회 실패 또는 DB 마이그레이션 미적용 | 빈 기록으로 오인하지 않도록 오류와 재시도 표시 |
| 서버 브라우저 오류 기록 | 서버 최신 200개에서 선택 기간을 필터링하므로 오래된 기록은 누락될 수 있음 |

# [엣지 케이스] 대시보드

| 상황 | 현재 동작 | 영향 / 다음 행동 |
| --- | --- | --- |
| 기록 없음 | 빈 상태와 선택 이동 버튼 | 새 실행 필요 |
| 앱 재시작 | 기록·요약 초기화 | userData 리포트도 UI에는 나타나지 않음 |
| 다중 실행 일부 실패 | 묶음 failed, 시나리오별 결과 표시 | 상세에서 메시지 확인·재실행 |
| 실행 취소 | `recordRun`을 호출하지 않음 | 대시보드 기록에 추가되지 않음 |
| 최근 5개 초과 | 오래된 메모리 record 제거 | 파일 리포트는 별도 유지 |
| 행의 키보드 포커스 | `tabIndex=0`이나 key handler 없음 | Enter/Space로 열리지 않음 |
| 상세 STEPS 수치 | 성공+실패 시나리오 수 표시 | 실제 단계 합계와 다를 수 있음 |

# [상태 연동] 대시보드

`web-scenario:listDashboardRuns`는 로그인 세션의 프로젝트로 범위를 제한하고 `web_runs`와 `api_scenario_runs`를 시작 시각 순으로 500건씩 끝까지 읽습니다. 기간은 기기 시간대 날짜를 ISO 시각으로 변환해 상한 제외 범위로 전달합니다. 웹 시나리오 스냅샷에서 제목과 환경을 읽으며 여러 환경이 섞이거나 환경이 없으면 환경 정보 없음으로 표시합니다. 기존 실행 화면의 최근 50개 복원은 별도입니다.

웹 상세는 `web-scenario:getRun`으로 선택한 실행의 스냅샷과 단계 결과를 조회합니다. API 시나리오 실행은 `ApiWorkspace.runScenario`에서 완료 후 `api_scenario_runs`에 UUID·프로젝트·시나리오 ID와 이름·환경 ID·상태·시작/종료 시각만 저장합니다. 실행 결과의 요청·응답·변수는 이 테이블에 넣지 않습니다. 저장 실패는 실행 결과와 별도로 경고합니다. MCP와 스위트에서 실제 실행된 시나리오도 같은 경로를 사용합니다.

`supabase/migrations/20261117000000_dashboard_api_runs.sql`은 프로젝트별 RLS와 인덱스를 정의합니다. 과거 API 실행 결과는 이전에 팀 DB에 보관하지 않았으므로 소급되지 않습니다. 스위트에서 삭제·초안 또는 필수 설정·선행 변수 문제로 실행 전에 차단된 항목도 별도 요약으로 저장합니다. 중단으로 건너뛴 항목은 저장하지 않습니다. DB 적용 전에는 통합 조회가 실패합니다.

브라우저 오류는 `liveSession.list("team")`의 최신 서버 기록 최대 200개에서 선택 기간과 오류 트리거가 있는 항목을 최대 5개 표시합니다. 선택하면 화면 테스트의 서버 기록 상세를 엽니다. 목록 조회 실패는 별도로 표시합니다.

# [사용자 흐름] 대시보드

1. 로그인된 프로젝트에서 하단 로고로 대시보드를 열면 선택 기간의 실행 기록을 조회합니다.
2. 기간 또는 웹·API 탭을 바꾸면 해당 데이터의 카드와 날짜별 실행을 확인할 수 있습니다.
3. 날짜, 상태, 환경, 검색어로 최근 실행 목록을 좁히고 페이지를 이동합니다. 카드의 실패·취소·설정 필요를 누르면 해당 유형과 상태를 적용합니다.
4. 웹 행을 누르면 실행 당시 기록의 상세 서랍을 열고 다시 실행할 수 있습니다. API 행은 실행 요약을 열고 API 테스트 화면으로 이동할 수 있습니다.
5. 조회 실패 시 오류와 재시도를 표시합니다. 기록이 없으면 웹 실행 또는 API 테스트로 이동할 수 있습니다.

# 예외 처리·제한·검증

| 상황 | 처리 |
| --- | --- |
| 형식·크기·시트·행·열·칸 상한 초과, 손상·암호 파일 | 가져오지 않고 이유 표시 |
| TC 머리글을 찾지 못함 | 가져오지 않음. 머리글이 없는 시트는 참고 시트로 비활성 |
| 필수 열 미매핑·빈 ID·중복 ID·빈 단계·빈 기대 결과 | 행 오류로 표시하고 선택 불가 |
| 선행 순환 | 준비에서 실행 불가 |
| CLI 미설치 | AI 탐색·AI 보조 실행은 안내 후 차단. 직접 데이터를 준비한 저장 절차의 빠른 실행은 가능 |
| 로그인·CAPTCHA·2차 인증 | 모델이 `handoff(login)` → 사용자 대기, 캡처 중지 |
| 자동 준비 중 지원하지 않는 파일 형식 | 해당 파일은 만들지 않고 TC 준비 메모에 형식과 직접 추가 안내를 남긴다. 다른 입력값과 지원 파일은 유지한다. `jpeg`는 `jpg`로 처리한다. |
| 자동 준비 파일이 10개 초과 | 실행기의 TC별 한도에 맞춰 10개를 준비하고 나머지는 준비 메모에 안내한다. |
| 자동 준비 실패 | TC별로 실패를 표시하고 나머지 선택 TC는 계속 준비한다. 재시도는 준비되지 않은 TC만 다시 요청한다. |
| 대상 다수 일치·미발견 | 모델에 사유 전달, 3회 연속이면 사용자 인계. 미발견만으로 Fail 아님 |
| AI 응답 중 화면 변경·관찰 실패 반복 | 이전 요청을 실행하지 않고 동작 이력에 기록한다. 연속 3회면 사용자에게 인계해 화면 확인 후 재개 또는 Blocked를 선택한다. |
| 화면 검사에 의한 인계 안내 | 대화 패널에서 앱 검사임을 구분하고 시나리오·TC, 시도한 동작, 중단 사유와 사용자에게 필요한 조치를 표시한다. 날짜 입력값의 시간 문자열은 세션 타이머 예외를 해제하지 않는다. |
| 세션 남은 시간의 초 단위 갱신 | 화면 변경 비교에서 `남은 시간 MM:SS` 버튼의 시간만 제외한다. 시간 확인이 TC나 AI 동작의 대상이거나 0초가 되면 변경을 그대로 감지한다. 모델에는 원래 화면을 전달한다. |
| 허용 도메인 밖 이동·리다이렉트 | 매 동작 뒤 최종 URL 확인 → 사용자 대기. `goto`는 실행 전 거부 |
| 새 탭 | 자동 전환하지 않고 사용자 대기 |
| 다운로드 | 저장하지 않고 취소, 사용자 대기 |
| alert / confirm·prompt | alert는 확인, confirm·prompt는 취소하고 다음 관찰에 내용을 알림 |
| 모델 오류·시간 초과·형식 오류 반복 | error 상태, 다시 시도 가능. Fail로 기록하지 않음 |
| 브라우저 종료 | 실행 오류로 종료, 확인된 결과 보존 |
| 앱 종료 | 실행 취소·브라우저 정리. 마지막 `result.json`까지만 남음 |
| 저장된 절차 불일치·손상 | 실행하지 않고 오류 표시. TC 원문·환경·데이터 이름을 확인 |
| 수동 단계·실패 후 우회가 포함된 절차 | 빠른 실행과 AI 보조 실행을 차단 |
| 재실행 검증 실패 | 해당 항목 Fail, 나머지는 확인 필요로 중단. 다음 등록·저장은 실행하지 않음 |
| 검증 문구가 준비 데이터 값을 포함 | 다음 실행에서 값이 달라질 수 있어 고정 검증 후보로 저장하지 않음. AI 보조 판정 필요 |
| 재실행 대상 미발견 | 중단. AI 보조 시 수정 후보를 제안할 수 있지만 자동 실행·저장하지 않음 |
| 토큰 사용량 미확인 및 토큰 한도 설정 | 다음 모델 호출 전 중단. 이미 진행한 호출은 한도를 초과할 수 있음 |

## 검증 (`npm run test:ai-tc`)

- 규칙: 매핑, 목록 분리, 행 오류, 병합·수식, 데이터 요구, 연쇄 해제, 선행 정렬·순환, 집계, 허용 도메인, 응답 스키마 거부.
- 엑셀: ExcelJS로 만든 예시 통합 문서(참고 시트, 병합, 리치 텍스트, 값 없는 수식, 숨김 행).
- 실행기: 테스트 전용 로컬 페이지 + headless Chromium + 가짜 모델로 입력·재관찰·판정, 데이터 변경 버튼 확인 없이 클릭, 도메인 이탈 Blocked, 선행 실패 Blocked(모델 미호출), 취소 후 늦은 응답 무시.
- Electron IPC·재시작: `npm run test:ai-tc:desktop`은 격리된 사용자 데이터와 가짜 CLI를 사용해 조건 승인 후 앱을 재시작하고 저장 절차를 AI 호출 없이 재실행한다. 실제 CLI와 UI 클릭을 대신 검증하지는 않는다.

## 짧게 표시되는 알림

일반 AI 실행은 직전 동작 이후 `role=alert`, `role=status`, `aria-live` 요소에 나타난 짧은 문구를 관찰 기록으로 모델에 전달한다. 현재 화면에 남아 있지 않을 수 있으며, 모델은 해당 동작과 기대 결과의 연관성을 판단한다. 이 속성이 없는 토스트, 페이지 이동으로 기록이 사라진 경우, 빠른 재실행은 이 방식으로 포착되지 않을 수 있다.

# 개요

하단 `화면 테스트`는 독립 브라우저 세션에서 폼 입력·네트워크 검사·응답 오버라이드를 수행하는 작업대입니다. 제공된 **Checkly 폼 자동 완성 v2** HTML을 기준으로 전용 52px 헤더, 상단 모드 탭, 440px 검사 패널을 사용합니다. 헤더 오른쪽에서 기록·모바일 앱·캡처를 엽니다. 세션마다 별도 persistent partition을 사용하므로 로그인과 쿠키가 서로 섞이지 않습니다.

폼 입력은 `입력칸 찾기 → 케이스 고르기 → 값 확인하고 입력` 순서입니다. 케이스를 선택하면 편집값과 대상 입력칸 번호를 표시하며, 하단 `N칸 입력하기`를 눌렀을 때만 대상 페이지를 변경합니다. 체크 해제한 필드는 입력·초기화에서 제외합니다. 첫 사용 안내는 닫은 상태를 저장합니다.

지원 입력은 일반 input·textarea, radio, checkbox, 단일·다중 select, contenteditable, file, 날짜·기간 선택 트리거입니다. 감지 결과로 정상값과 유효성 오류값 케이스를 만들며, 사용자가 값을 편집해 현재 화면 범위에 저장할 수 있습니다. `지금 화면 값으로 새 케이스`는 페이지의 현재 값을 읽어 저장합니다. 보안상 실제 파일 경로나 읽을 수 없는 날짜 팝업 값은 복제하지 않습니다.

## 제공 기능

- `폼 입력`: 자동 필드 감지, 정상·오류 케이스, 필드별 입력 선택, 사용자 케이스 저장·삭제, 선택 필드 초기화
- `네트워크`: fetch/XHR·페이지 오류, 전체·오류·스펙 경고 필터, 상세 요청·응답 표 및 원본 JSON, API 스펙 복사, XLSX 다운로드·전체 삭제
- `Swagger`: 기존 설정의 문서 연결과 계약 검증, 서버 주소와 경로·메서드로 자동 연결, 스키마 상세 확인
- `응답 오버라이드`: 응답 복제·직접 생성, method/path·상태 코드·JSON 또는 항목 편집, 규칙별 적용 스위치, 초기화·삭제
- `브라우저 기록`: 오류 전후 5초 자동 기록, 목록·재생·타임라인·MP4·서버 전송. 기록 화면을 열어도 웹뷰 수집은 유지
- `모바일 앱`: 시뮬레이터·앱 선택, 연결·홈·재시작·입력, RN 연결 안내, 네트워크·오버라이드·캡처
- `캡처`: 영역 선택, 펜·네모·체크·텍스트·지우개, 색상·굵기·실행 취소, PNG 클립보드 복사
- `보기`: 브라우저 식별, viewport 프리셋·회전, 50~125% 배율, 개발자 도구·화면 집중

브라우저 네트워크 훅과 팝업 처리는 `persist:checkly-form-automation*` partition에만 적용됩니다. 작업대는 창 전체 너비를 사용하며, 검사 패널 너비 조절·세션 분할·케이스 목록 높이 조절을 유지합니다. 디자인 및 검증 기준은 [v2 디자인](05-design.md)에 정리합니다.

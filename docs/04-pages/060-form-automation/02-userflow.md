# 사용자 흐름

1. 하단 `폼 자동 완성` 탭으로 이동합니다.
2. 주소를 입력하거나 독립 로그인 세션을 추가합니다.
3. 페이지 로드 후 필드를 자동 감지합니다.
4. 정상 또는 실패 케이스를 눌러 즉시 입력합니다.
5. 필요하면 값을 수정해 현재 화면 케이스로 저장합니다.
6. `현재 입력값 초기화`로 감지된 필드를 비웁니다.

## 네트워크와 Swagger

1. `Swagger 연결`에서 OpenAPI JSON URL을 입력하거나 로컬 JSON 파일을 선택합니다.
2. 대상 페이지에서 API 요청을 발생시킵니다.
3. `네트워크` 탭에서 전체 또는 오류 요청을 필터링하고 상세 내용을 확인합니다.
4. 연결된 명세가 있으면 응답 계약 일치 여부와 오류 경로를 확인합니다.
5. `API 스펙 복사`, `로그 다운로드`, `전체 삭제`로 결과를 전달하거나 정리합니다.
6. 요청 목록 아래의 핸들을 드래그해 목록 높이를 조절하고, 더블클릭해 기본 높이로 되돌립니다.

## 저장소와 오버라이드

1. `저장소` 탭에서 현재 브라우저 세션의 localStorage, sessionStorage, 쿠키를 조회합니다.
2. key 또는 value로 검색하고 항목별 혹은 전체 값을 복사합니다.
3. 네트워크 상세에서 `오버라이드 만들기`를 눌러 실제 응답을 복제합니다.
4. `오버라이드` 탭에서 exact method/path, 상태 코드, 응답 JSON을 편집합니다.
5. 규칙을 저장하면 현재 웹뷰에 적용되고, 다음 일치 요청부터 편집한 응답을 사용합니다.

## 화면 캡처와 배율

1. 상단 `화면 캡처`를 누르거나 `⌘/Ctrl + Shift + S`를 입력해 현재 LIVE QA 작업 화면 이미지를 엽니다. 단축키는 대상 웹뷰에 키보드 포커스가 있어도 동작합니다.
2. 처음 활성화되는 `영역 선택` 도구로 필요한 부분을 드래그합니다. 선택이 끝나면 캔버스가 해당 영역으로 잘리고 `펜` 도구로 자동 전환됩니다.
3. 펜을 포함한 주석 도구는 잘린 캡처 영역 안에서만 동작합니다. 원본 전체 화면으로 돌아가려면 `전체 화면`을 누릅니다.
4. 펜·네모·체크·텍스트·지우개와 색상·굵기를 선택해 표시합니다.
5. 실행 취소 후 완성 이미지를 PNG로 클립보드에 복사합니다.
6. 주소창 오른쪽의 `-`, 퍼센트, `+`로 화면 배율을 조절하며 퍼센트를 누르면 100%로 돌아갑니다.

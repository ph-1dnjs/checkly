# 사용자 흐름

1. 하단 `폼 자동 완성` 탭으로 이동합니다.
2. 주소를 입력하거나 독립 로그인 세션을 추가합니다.
3. 페이지 로드 후 필드를 자동 감지합니다.
4. 정상 또는 실패 케이스를 눌러 편집 대상으로 선택합니다. 이때 대상 폼은 바뀌지 않습니다.
5. 오른쪽 필드별 체크박스에서 입력하지 않을 필드를 해제하고, 필요한 값을 수정합니다. `전체 선택`과 `전체 해제`도 사용할 수 있습니다.
6. `선택한 N개 필드 입력`을 누르면 저장 전 수정값까지 반영됩니다. 체크 해제한 필드의 기존 값은 그대로 둡니다.
7. 필요하면 값과 체크 상태를 현재 화면 케이스로 저장합니다. `선택 필드 초기화`도 체크된 필드에만 적용됩니다.

## 네트워크와 Swagger

1. 설정/API 테스트에 등록된 Swagger 문서를 재사용합니다. 요청 상세 상단의 Swagger 상태 버튼을 누르면 연결 문서 선택과 새로고침을 열 수 있습니다.
2. 대상 페이지에서 API 요청을 발생시킵니다.
3. `네트워크` 탭에서 전체 또는 오류 요청을 필터링하고 상세 내용을 확인합니다.
4. 연결된 명세가 있으면 응답 계약 일치 여부와 오류 경로를 확인합니다.
5. 요청 상세 상단 오른쪽의 `API 스펙 복사`와 `응답 오버라이드`로 내용을 복사하거나 응답 규칙을 만듭니다. 타임라인의 `다운로드`, `전체 삭제`로 기록을 전달하거나 정리합니다.
6. 요청 목록 아래의 핸들을 드래그해 목록 높이를 조절하고, 더블클릭해 기본 높이로 되돌립니다.

Swagger 연결 설정은 미연결·서버 주소 불일치·문서 조회 오류가 있어도 기본으로 접어두고, 상태 버튼에 확인 필요 여부나 오류 건수만 표시합니다. 설정을 열어도 서버·API 경로·가져온 시각은 `문서 상세`, 긴 오류 내용은 `문서 불러오기 실패`를 눌러 확인합니다. 문서를 선택하면 설정을 접어 요청·응답 필드로 돌아갑니다.

## 오버라이드

1. 네트워크 상세에서 `오버라이드 만들기`를 눌러 실제 응답을 복제합니다.
2. `오버라이드` 탭에서 exact method/path, 상태 코드, 응답 JSON을 편집합니다.
3. 규칙을 저장하면 현재 웹뷰에 적용되고, 다음 일치 요청부터 편집한 응답을 사용합니다.

## 화면 캡처와 배율

1. 상단 `화면 캡처`를 누르거나 `⌘/Ctrl + Shift + S`를 입력해 현재 LIVE QA 작업 화면 이미지를 엽니다. 단축키는 대상 웹뷰에 키보드 포커스가 있어도 동작합니다.
2. 처음 활성화되는 `영역 선택` 도구로 필요한 부분을 드래그합니다. 선택이 끝나면 캔버스가 해당 영역으로 잘리고 `펜` 도구로 자동 전환됩니다.
3. 펜을 포함한 주석 도구는 잘린 캡처 영역 안에서만 동작합니다. 원본 전체 화면으로 돌아가려면 `전체 화면`을 누릅니다.
4. 펜·네모·체크·텍스트·지우개와 색상·굵기를 선택해 표시합니다.
5. 실행 취소 후 완성 이미지를 PNG로 클립보드에 복사합니다.
6. 주소창 오른쪽의 `-`, 퍼센트, `+`로 화면 배율을 조절하며 퍼센트를 누르면 100%로 돌아갑니다.

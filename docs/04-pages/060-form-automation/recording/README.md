# 브라우저 기록 · 팀 로그

테스트 브라우저와 웹 시나리오의 화면을 rrweb 2.1.7로 수집한다. 평소에는 메모리 버퍼만 유지하고, 오류 발생 전 5초·후 5초를 앱에서 재생할 수 있는 기록으로 저장한다(WebM/MP4가 아님).

로그인한 팀 모드에서는 API 호출·페이지 이동·오류의 메타데이터를 Supabase에 전송하고, 오류 기록만 비공개 Storage에 압축 업로드한다. 로그아웃 상태에서는 기존 로컬 오류 기록만 저장한다.

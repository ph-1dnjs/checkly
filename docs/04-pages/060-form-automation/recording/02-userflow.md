# 사용 흐름

1. 폼 자동 완성에서 사이트를 열면 자동 수집한다. 별도 시작·종료 버튼은 없다. 정상 동작의 화면은 파일이나 서버에 저장하지 않는다.
2. 로그인한 경우 API 호출(fetch/XHR)의 URL·메서드·상태·소요시간, 페이지 이동, 오류 종류만 팀 DB에 최대 5초 간격으로 전송한다. 웹 시나리오도 API 호출과 이동·오류를 수집한다.
3. HTTP 400 이상·네트워크 실패·페이지 오류·미처리 Promise·console.error·리소스 오류가 발생하면 전 5초·후 5초를 저장한다. 같은 후속 5초 안의 오류는 한 클립으로 합치되 각각 로그는 남긴다.
4. 팀 모드는 마감된 오류 기록을 gzip으로 비공개 Storage에 업로드한다. 실패해도 로컬 사본을 보존하고 같은 계정에서 자동 재시도한다.
5. 헤더의 **브라우저 기록**에서 기록을 선택해 재생·일시정지·탐색·배속을 사용한다. 팀 모드는 같은 프로젝트의 최근 200개 기록과 이 PC의 업로드 대기 기록을 보여 준다. 페이지·팝업은 문서 선택으로 확인한다.
6. 팀 기록 삭제는 Storage 파일과 DB 목록을 지운다. 로컬 모드에서는 로컬 파일만 지운다. 수집 중인 기록은 삭제할 수 없다.
7. 로그아웃·계정/프로젝트 변경 시 미전송 로그와 메모리 버퍼를 비운다. 이전 프로젝트의 파일을 새 프로젝트로 업로드하지 않는다. 브라우저나 앱을 일찍 닫으면 후속 구간은 종료 시점까지다.

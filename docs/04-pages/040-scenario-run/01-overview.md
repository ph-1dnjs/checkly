# [개요] 시나리오 실행

> **범위**: 실행 요청부터 전체 시나리오의 통과·실패·취소와 결과 다운로드까지입니다.

각 시나리오는 URL 접속 후 단계 순서대로 실행합니다. 자동 단계는 locator 탐색과 Playwright 동작을 사용하고, 수동 입력·직접 제어·결과 확인 단계는 renderer에 이벤트를 보내 최대 5분 응답을 기다립니다. 실행 종료 시 JSON/HTML 리포트와 영상이 `userData`에 기록됩니다.

다중 선택 실행은 `App`이 순서대로 호출하고 worker ID로 브라우저 context를 재사용합니다.

# [엣지 케이스] 시나리오 선택

| 상황 | 현재 동작 | 영향 / 다음 행동 |
| --- | --- | --- |
| 폴더 미선택 | 빈 안내 | 폴더 선택 |
| 저장 폴더 삭제·권한 오류 | null+빈 목록 | 다시 선택 |
| Markdown 파일 없음 | 빈 상태 | 파일 추가 후 다시 불러오기 |
| 파일에 단계 없음 | FILES에서 제외 | 문법 수정 |
| 일부 파일 read 실패 | 해당 파일 제외 가능 | 권한 확인 |
| 미선택 | 묶음 실행 disabled | 단일 play 또는 선택 |
| 선택 후 새로고침 | key state는 남아도 목록 기반 결과만 실행 | 선택 재확인 |
| 중복 제목 | filePath+scenario.id로 구분 | 같은 파일 id는 parser 순서 기반 |
| 하위 폴더 파일 | 탐색하지 않음 | 선택 폴더 바로 아래로 이동 |
| connected 표시 | 실제 inspect 결과가 아님 | 실행 성공을 보장하지 않음 |

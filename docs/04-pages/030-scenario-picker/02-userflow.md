# [사용자 흐름] 시나리오 선택

```mermaid
flowchart TD
  A[화면 진입] --> B[저장 폴더 목록]
  B --> C[모든 파일 읽기·파싱]
  C --> D{실행 가능 파일}
  D -->|없음| E[폴더 선택/새로고침/편집기]
  D -->|있음| F[파일 선택]
  F --> G[시나리오 선택·단계 펼침]
  G --> H{실행 방식}
  H -->|단일 play| I[한 시나리오]
  H -->|선택 실행| J[파일 순서의 묶음]
  I --> K[실행 화면]
  J --> K
```

| 액션 | 동작 |
| --- | --- |
| 폴더 변경 | native directory dialog 후 경로 저장·전체 재로드 |
| 파일 다시 불러오기 | 저장 폴더를 다시 읽어 cache 교체 |
| 시나리오 행 | 선택 집합 toggle |
| 단계 | 펼침 집합 toggle |
| 단일 play | 선택 여부와 무관하게 한 개 실행 |
| 카트 비우기 | 모든 선택 해제 |
| 선택 실행 | 선택된 Scenario 배열을 App에 전달 |

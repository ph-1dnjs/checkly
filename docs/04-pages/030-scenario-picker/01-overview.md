# 개요

DB 목록은 문서 수정 시각 내림차순이다. 각 문서의 Markdown을 파싱하고 저장된 마커를 복원한다. 실행 선택은 문서 UUID와 블록 순서로 구분하며 문서 목록 순서와 블록 순서로 실행한다.

편집기에서 저장·삭제하면 같은 목록에 즉시 반영한다. 다른 팀원의 변경은 새로고침으로 조회한다. 현재 목록에 없는 선택 ID는 실행 대상과 선택 개수에서 제외한다. 초안은 이 목록에 포함하지 않는다.

편집기와 같은 `ScenarioList`로 DB 문서를 고르고, 가운데에서 문서 안의 시나리오를 선택한다. 전체 선택은 현재 문서에만 적용하며 다른 문서의 선택은 유지한다. 기존 `ActionTag` 단계 표시와 문서별 실행 대상·시나리오 수·단계 수 요약을 재사용한다. 좁은 화면에서도 문서 목록은 유지하고 실행은 하단 공통 실행 버튼을 사용한다.

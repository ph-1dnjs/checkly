# [엣지 케이스] 설정

| 상황 | 현재 동작 | 영향 / 다음 행동 |
| --- | --- | --- |
| URL 없음 | `—` 표시 | 실행 가능 여부와 연결되지 않음 |
| 화면 이탈 후 재진입 | 컴포넌트가 다시 mount되면 기본 토글로 초기화 | 변경 유지 안 됨 |
| 앱 재시작 | 모든 토글 초기화 | 영속 설정 없음 |
| “변경” 클릭 | 아무 동작 없음 | 브라우저는 계속 Chromium |
| 영상 보관 off | 실행 영상은 계속 생성 | 표시와 실행 정책 불일치 |
| 실패 알림/Slack on | 알림을 보내지 않음 | 외부 연동 없음 |
